# Day 01 – Intro To Python

## 1. What is Programming?

Programming is the process of writing instructions that tell a computer what to do. These instructions are written in a programming language and are called a **program**. Programming helps computers solve problems, perform calculations, and automate tasks.

---

## 2. What is Python?

Python is a **high-level, interpreted programming language** used to develop software, automate tasks, analyse data, and build websites or artificial intelligence systems.  

Python was created by **Guido van Rossum** and released in **1991**.

---

## 3. Features of Python

### i. Simple and Easy to Learn
Python has a very simple syntax that is close to the English language. Because of this, beginners can learn it quickly and write programs easily compared to many other programming languages.

### ii. High-Level Language
Python is a high-level programming language, which means programmers do not need to manage complex hardware details. It focuses more on solving problems rather than dealing with low-level system operations.

### iii. Interpreted Language
Python programs are executed line by line by an interpreter instead of being compiled first. This makes debugging easier because errors can be found quickly during program execution.

### iv. Platform Independent
Python programs can run on different operating systems such as **Windows, Linux, and macOS** without changing the code. This makes Python very flexible for developers.

### v. Object-Oriented Language
Python supports object-oriented programming concepts such as **classes, objects, inheritance, and encapsulation**. These features help programmers build large and complex applications more efficiently.

### vi. Large Standard Library
Python provides a large collection of built-in libraries and modules that help developers perform tasks such as **file handling, web development, data processing, and automation** easily.

### vii. Open Source
Python is open-source software, which means it is free to use and modify. Anyone can download it, use it, and improve it without paying any license fees.

### viii. Supports Multiple Programming Styles
Python supports different programming styles such as **procedural programming, object-oriented programming, and functional programming**. This allows developers to solve problems using different approaches.

# What is Python Used For?

Python is used to create many types of software and technology solutions. Because it is simple and powerful, it is used in many fields.

### i. Web Development
Python is used to build websites and web applications. Frameworks like **Django** and **Flask** help developers create secure and scalable websites.

### ii. Artificial Intelligence and Machine Learning
Python is widely used in **AI and machine learning**. Many AI tools and libraries are built using Python. Companies like **Google** and **Netflix** use Python for AI-related work.

### iii. Data Analysis and Data Science
Python helps analyse large amounts of data. Libraries like **Pandas** and **NumPy** allow programmers to study data, find patterns, and make predictions.

### iv. Automation
Python can automate repetitive tasks such as **renaming files, sending emails, and collecting information from websites**.

### v. Game Development
Python can be used to develop simple games and prototypes using libraries like **Pygame**.

### vi. Software Development
Python is used to build **desktop applications, tools, and software systems**.

### vii. Cybersecurity and Ethical Hacking
Python is often used in cybersecurity to create **testing tools, automate security checks, and analyse vulnerabilities**.
