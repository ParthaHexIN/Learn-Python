# 1. upper() Method

Converts all characters to UPPERCASE

## Syntax

```python
string.upper()
```

---

## Example

```python
text = "hello world"
print(text.upper()) #output:"HELLO WORLD"
```

# 2. lower() Method
Converts all characters to lowercase.

## Syntax

```python
string.lower()
```

---

## Example

```python
text = "HELLO WORLD"
print(text.lower()) #output: hello world
```


# 3. title() Method
Converts the first letter of each word to capital letter.

---

## Syntax

```python
string.title()
```

---

## Example

```python
text = "hello world"
print(text.title()) #output: Hello World
```
# 4. capitalize() Method
Converts only the first letter of the first word to capital letter and makes the rest lowercase.

---

## Syntax

```python
string.capitalize()
```

---

## Example

```python
text = "hello world"
print(text.capitalize()) #output:Hello world
```
