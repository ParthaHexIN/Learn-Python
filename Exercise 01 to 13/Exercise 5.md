# Break, Continue, and Pass Statements - Practice Questions

---

## 1. Using break

Write a program that:

- Uses a `for` loop to print numbers from `1` to `10`  
- Stops the loop when the number becomes `7` using `break`  

👉 Expected Output:

```
1
2
3
4
5
6
```
## 2. Using continue

Write a program that:

- Prints numbers from 1 to 10
- Skips the number 5 using continue

👉 Expected Output:
``` 
1
2
3
4
6
7
8
9
10
``` 

## 3. Using pass

Write a program that:

- Uses a loop from 1 to 5
- Does nothing for number 3 using pass
