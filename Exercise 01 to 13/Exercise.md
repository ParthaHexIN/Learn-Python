# If-Else Conditional Statements - Practice Questions

---

## 1. Positive, Negative, or Zero

Write a program that:

- Asks the user for a number  
- Prints whether it is:
  - Positive  
  - Negative  
  - Zero  

---

## 2. Voting Eligibility

Create a program that:

- Takes age as input from the user  
- Checks if the person is eligible to vote  

 Condition: age ≥ 18  

- If eligible → print "You are eligible to vote"  
- Otherwise → print "You are not eligible to vote"  

---

## 3. Even or Odd

Write a program that:

- Takes a number from the user  
- Prints:
  - "Even" if the number is even  
  - "Odd" otherwise
