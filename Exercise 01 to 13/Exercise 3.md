# For Loops - Practice Questions

---

## 1. Print Numbers from 1 to 10

Write a program that:

- Uses a `for` loop  
- Prints numbers from `1` to `10`  

---

## 2. Multiplication Table

Write a program that:

- Asks the user to enter a number  
- Prints the multiplication table of that number  

👉 Example (for 5):

``` "
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50
```
## 3. Sum of Numbers from 1 to 100

Write a program that:

- Uses a for loop
- Calculates the sum of all numbers from 1 to 100
- Prints the final sum

## 4. Pattern Printing

Write a program that prints the following pattern using a for loop:
```
*
**
***
****
```
