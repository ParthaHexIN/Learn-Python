# Introduction to Strings in Python

## Introduction

Strings are one of the most fundamental data types in Python. A string is a sequence of characters enclosed within either:

- Single quotes `' '`
- Double quotes `" "`
- Triple quotes `''' '''` or `""" """`

Strings are used to store and manipulate text data such as:

- Names  
- Messages  
- Addresses  
- Sentences  

A string can contain:

- Letters  
- Numbers  
- Symbols  
- Spaces  
- Special characters  

Python treats each character in a string as an individual element and assigns an **index position** to it.

---

## Example

```python
name = "Partha"

message = 'Hello World'

paragraph = """Python is
easy to learn"""
```


## Creating Strings

You can create strings in Python using different types of quotation marks. Python supports:

- Single quotes  
- Double quotes  
- Triple quotes  

for defining strings.

- **Single quotes (`' '`)** are used for simple strings.  
- **Double quotes (`" "`)** work the same way as single quotes.  
- **Triple quotes (`''' '''` or `""" """`)** are mainly used for creating multi-line strings or long text blocks.  

---

## Example

```python
# Single-quoted string
a = 'Hello, Python!'

# Double-quoted string
b = "Hello, World!"

# Triple-quoted string (useful for multi-line strings)
c = '''This is
a multi-line
string.'''
```
